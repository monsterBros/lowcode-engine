# 大纲树拖拽移动功能文档

## 功能说明

大纲树支持通过拖拽来重新组织组件层级结构。

## 使用方法

### 1. 拖动节点
- 鼠标悬停在节点上
- 按住左键拖动

### 2. 放置到容器
- 拖到目标Container组件上
- 看到高亮提示
- 松开鼠标完成移动

## 功能限制

- ❌ root节点不能拖拽
- ❌ 只能拖到容器组件
- ❌ 不能拖到自己或子节点
- ❌ 锁定的节点不能移动

## 视觉反馈

- 🎨 拖拽中：节点半透明
- 🎯 可放置：目标高亮
- 🔒 已锁定：灰色显示

## 技术实现

使用react-dnd库实现拖拽功能：
- `useDrag` - 使节点可拖拽
- `useDrop` - 使容器可接收
- `moveNode` - 更新schema结构

## 示例

**移动Button到Container**:
```
拖拽前：
- root
  - Button1
  - Container1

拖拽后：
- root
  - Container1
    - Button1 ✅
```
